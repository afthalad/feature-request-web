## Planning Rubric

### 1. What is this project?
Fewchurs is a feature-request platform for indie iOS developers. Developers sign in with Google, create an app, get an API key, embed it in their iOS app, and let users submit and upvote feature requests. Developers see everything in a dashboard, manage status, get email notifications, and choose from three pricing tiers.

### 2. Who is the audience?
Indie iOS developers and small app teams looking for a lightweight, modern way to collect and prioritize user feedback.

### 3. What should they feel?
"This is built with serious tech, it's trustworthy, and it was made by someone who understands modern development."

### 4. What's the hook?
First 2–3 seconds: Show a feature request card with upvotes. Text: "Users want features. You need to know what."

### 5. What's the main thing?
The dashboard: clean, full-featured, shows apps, feature requests, comments, votes. The developer experience: modern stack (Next.js 15, React 19, TypeScript, Firestore), Google OAuth, Resend emails, payment processing.

### 6. Why does the tech stack matter?
Indie devs care about tools that are fast, reliable, and built on modern foundations. Showing the stack (Next.js 15, Firebase, TypeScript, Tailwind) signals quality and trustworthiness. Listing tech also appeals to developers who want to understand what powers the platform.

### 7. What's the format and pacing?
Extended format to give each tech stack element its moment without feeling rushed. 35 seconds allows proper reveal of:
- Hook (3s): Problem statement with feature card
- Reveal (5s): Dashboard UI tour
- Tech deep-dive (15s): Frontend, Backend, Database, Auth, Email, Payments—each 2–3 seconds
- Social proof (4s): Pricing tiers / call to action
- Outro (3s): Brand, tagline

### 8. What visuals?
- Real dashboard screenshots / UI elements
- Tech stack logos (Next.js, React, Firebase, TypeScript, Tailwind, Google, Resend, PayHere)
- Clean typography, modern transitions
- Subtle motion on cards and logos
- Frame rate: 60fps
- Smooth fade/slide transitions between sections

### 9. What's the angle?
"Modern platform, modern stack." Position Fewchurs as the go-to solution for devs who care about code quality, infrastructure, and developer experience.

## Creative Notes

1. **Readability:** Each tech logo/text settles for ~2–3 seconds minimum before transition.
2. **Specificity:** Use real Fewchurs UI screenshots, not generic placeholders.
3. **No SaaS clichés:** Avoid "streamline," "unlock," generic hands-on-keyboard shots.
4. **Show the thing:** Dashboard must be real and legible—this is the core product.
5. **Tech stack as storytelling:** The stack isn't a laundry list; it's a narrative: modern frontend, secure backend, global payments, developer-first API.
6. **iOS developer perspective:** Emphasize ease of embedding, real API, not another white-label black-box solution.
